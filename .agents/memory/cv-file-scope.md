---
name: CV upload format scope
description: PDF-only product requirement; images, Word and OCR are intentionally excluded.
---

CV uploads must accept PDF only. Images, Word/DOCX and OCR are outside the requested product scope, not future features to add or propose by default.

**Why:** The user explicitly clarified that resumes must be PDF only and rejected support for images, OCR and DOCX.

**How to apply:** Preserve this scope in picker filters, pre-upload checks, server validation and user-facing descriptions. Explain unreadable or scanned PDFs without adding OCR. Revisit other formats only if the user explicitly changes this requirement.
