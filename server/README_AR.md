# تحليل السيرة — خادم التجربة المحلية

1. في Replit شغّل المشروع من زر Run. يبدأ Expo وخادم التحليل معًا، والخادم محمي خلف جلسة Supabase وعلى Unix socket داخلي؛ لا تعرض منفذًا عامًا له.
2. تشغيل `npm --prefix server test` يفحص الخادم محليًا دون مزود تحليل خارجي.
3. لا تضف `GROQ_API_KEY` إلى التطبيق أو بمتغير يبدأ `EXPO_PUBLIC_`. غياب المفتاح يعيد 503 واضحًا دون تحليل محلي بديل. افتراضي تحليل السيرة `openai/gpt-oss-120b` عبر Groq API فقط مع JSON Schema صارم. يمكن تجاوز النموذج عبر `GROQ_MODEL`؛ تحقق من أنه لا يفرض نموذجًا أقدم. لا تغيّر المتغير المشترك بلا قصد لأن المقابلة الحالية تستخدمه أيضًا. يلزم المفتاح الخادمي وموافقة المستخدم قبل الإرسال.

الملف يُقرأ مؤقتًا في ذاكرة الخادم ولا يحفظ الخادم نسخة منه أو يسجل المحتوى. تحليل Groq يرسل النص إلى المزوّد بعد الموافقة. رفع السيرة يقبل PDF إنجليزيًا يحتوي نصًا مقروءًا فقط؛ الصور وWord/DOCX غير مقبولة ولا يوجد OCR. يُفحص الامتداد ونوع المحتوى وبصمة PDF عند الاختيار وقبل الرفع، ثم يتحقق الخادم من نوع الملف ومحتواه وقابليته للقراءة. حدود التجربة: 10 ميجابايت، 15 صفحة PDF، 24000 حرف. يتم رفض النص الطويل دون قطع صامت.

المعلومات المستخرجة اقتراحات تحتاج مراجعة، والاستشهاد النصي يثبت وجود النص فقط ولا يثبت صحة الشهادة أو إتقان المهارة. المطابقة تستخدم أسماء SSF ومرادفات عربية وإنجليزية. المهارة ترفع النسبة عندما تطابق متطلبًا أساسيًا للمسار فقط؛ التفاصيل والمصادر في docs/DATASET_AND_SCORING_AR.md. الشهادات والخبرات تحفظ للمراجعة ولا تدخل حساب التغطية الحالي.

الخادم يتحقق من access token لدى Supabase قبل معالجة ملف السيرة. هذا وحده لا يعني أنه جاهز للنشر العام؛ تبقى مراجعة الخصوصية والاحتفاظ والحذف والحماية واختبارات المنصة الفعلية مطلوبة. استخدم سيرة تجريبية فقط.

المصادر: https://console.groq.com/docs/structured-outputs وhttps://console.groq.com/docs/your-data

القواعد المحلية باقية للتحقق والاستكمال الحرفي بعد رد Groq وللاختبارات، وليست بديلًا تشغيليًا عند غياب المفتاح. تحفظ أدلة النص وأرقام صفحات الحقول التي يمكن تحديدها دون تخمين. قد تفوت التنسيقات الحرة أو متعددة الأعمدة؛ البنود الملتبسة تبقى للمراجعة. راجع `docs/GROQ120_CV_CHECK_AR.md`.

هذا استخراج قائم على قواعد، وليس تحليل AI كاملًا. يدعم الخبرة المكتوبة بوضوح في سطر مثل `Software Engineer at Sample Labs, 2021 - 2023` أو `مهندسة لدى شركة آفاق، يناير ٢٠٢١ - مارس ٢٠٢٣`، والحقول المتتالية ذات التسميات الصريحة مثل المسمى/الجهة/الفترة/المهام أو Role/Company/Period/Description. لا يربط جهة أو فترة من صف آخر ملتبس ولا يحسب مدة خدمة أو يستنتج مهارة من المسمى. النتائج قابلة للتصحيح والاستبعاد في واجهة المراجعة قبل حفظها.
