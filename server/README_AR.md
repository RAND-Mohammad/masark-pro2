# خادم تحليل السيرة الذاتية

## المسار المعتمد

يقبل الخادم ملف PDF نصيًا بعد التحقق من جلسة Supabase وموافقة المستخدم. يستخرج PDF.js النص مع ترتيب الصفحات والأسطر، ثم يرسل الملف والنص إلى **Google Gemini API** بالمخطط المنظم. بعد ذلك يتحقق الخادم من بنية الرد ومن وجود دليل نصي لكل حقل قبل عرضه للمراجعة. لا يعتمد التطبيق النتيجة حتى يراجعها المستخدم.

- النموذج الحالي: `gemini-3.8-flash` مع structured output ومستوى تفكير medium.
- المفتاح الخادمي المطلوب اسمه `Gemini_API_Key_masarak`. يضاف في Replit Secrets أو بيئة الخادم فقط؛ لا تضفه إلى التطبيق أو متغير يبدأ بـ`EXPO_PUBLIC_` ولا تحفظ قيمته في Git.
- لا يستخدم مسار تحليل السيرة Groq. Groq يبقى منفصلًا لتقييم إجابات المقابلة فقط.
- إذا كان المفتاح ناقصًا أو رفض Gemini الطلب أو لم يطابق الرد التحقق، يتوقف التحليل برسالة خطأ؛ لا يوجد fallback محلي يوصف بأنه ذكاء اصطناعي.
- المعالجة المحلية تقرأ تخطيط PDF، وتتحقق من الأدلة، وتستعيد أسماء المهارات المكتوبة حرفيًا عند الحاجة؛ لا تخمّن مهارة أو مؤهلًا ولا تستبدل تحليل Gemini.

## حدود الملفات والخصوصية

يدعم التدفق PDF نصيًا باللغة الإنجليزية، حتى 10 ميجابايت و15 صفحة و24,000 حرف مستخرج. الصور وWord/OCR غير مدعومة. يرسل الخادم الملف والنص إلى Google بعد موافقة المستخدم، ولا يسجل محتوى السيرة. في خطة Google المجانية قد تُستخدم بيانات الطلبات لتحسين منتجات Google؛ للاختبار استخدموا سيرة وهمية أو منقحة فقط، وراجعوا خطة المفتاح قبل أي استخدام ببيانات حقيقية.

تتضمن النتيجة المهارات، التعليم، المشاريع، الخبرات، الدورات والشهادات. تبقى الحقول غير المدعومة باقتباس وصفحة مطابقين فارغة للمراجعة. الاقتباس يثبت أن العبارة موجودة في PDF ولا يثبت صحة المعلومة أو الإتقان. لا يضمن النظام التقاط كل صيغة أو تخطيط، ولا يقرر القبول الوظيفي. نطاق PDF الإنجليزي النصي فقط مقصود ومتوافق مع Phase 1؛ لم نضف OCR أو مستندات Word.

## تشغيل واختبار محلي

1. من مجلد المشروع ثبّت الحزم: `npm ci` ثم `npm --prefix server ci`.
2. انسخ `.env.example` إلى `.env` واملأ رابط Supabase والمفتاح العام.
3. انسخ `server/.env.example` إلى `server/.env` واملأ القيمتين نفسيهما ومفتاح Gemini. لا تضع هذه الملفات في Git ولا تشارك مفتاح Gemini.
4. في نافذتي Terminal داخل VS Code شغّل `npm run cv-server` ثم `npm start`. للتجربة في المتصفح استخدم `npm run web` بدل `npm start`.
5. تأكد من أن الكمبيوتر متصل بالإنترنت وأن المشروع في Supabase يسمح بتسجيل الدخول. يحتاج تحليل PDF إلى مفتاح Gemini بحصة متاحة.

اختبارات الخادم المحلية تستخدم ملفات PDF اصطناعية ولا تتطلب إرسال سيرة أو استعمال Gemini: `npm --prefix server test`.

اختبارات المحاكاة لا تثبت أن المفتاح أو الحصة يعملان لدى Google. لاختبار التكامل الحقيقي استخدموا PDF اصطناعيًا أو منقحًا فقط، وسجّلوا أن الطلب مرّ إلى Gemini لا إلى fallback. لا تختبروا بسيرة حقيقية على الخطة المجانية.

للتفاصيل الحالية وحدود النطاق راجعوا `docs/GEMINI_CV_ANALYSIS_AR.md` و`docs/FR3_RESUME_REVIEW_AR.md`.
