- واجهات الترحيب والدخول والصفحة الرئيسية والملف.

## التشغيل
ثبّتوا Node.js، وافتحوا مجلد masarak في VS Code. من الطرفية:

```powershell
npm ci
npm --prefix server ci
```

انسخوا .env.example إلى .env.local بجذر التطبيق، واملؤوا رابط Supabase ومفتاح publishable. انسخوا server/.env.example إلى server/.env واملؤوا مفتاح Groq. اطلبوا بيانات الوصول من صاحبة المشروع بشكل خاص أو أنشئوا خدمات مجانية خاصة بكم. لا تضيفوا مفاتيح إلى Git ولا ترسلوها في صور أو مجموعة.

التشغيل المختصر:
```powershell
npm.cmd start -- --clear
```
يشغّل Expo وخادم Node.js معًا على الكمبيوتر. افتحوا Expo Go وامسحوا QR؛ يجب أن يكون الهاتف والكمبيوتر على الشبكة نفسها. يمكن تشغيل الخادم وحده عند الحاجة عبر `npm.cmd run cv-server`.

على الهاتف، افتحوا Expo Go وامسحوا QR، مع اتصال الهاتف والكمبيوتر بالشبكة نفسها. قد يطلب جدار الحماية السماح لـNode على الشبكة الخاصة.

## أين نكمل
1. بقي تطبيق `supabase/admin_remaining_setup.sql` في SQL Editor بعد التأكد أن migrations 005–007 لم تُطبّق مسبقًا. بعد التنفيذ، شغّلوا `supabase/verify_admin_migrations.sql` للتأكد من ظهور الجداول والأعمدة المطلوبة.
2. بعد إعداد قاعدة البيانات، جرّبوا دخول لوحة الإدارة بحساب المشرفة، ثم إضافة مورد تعليمي والتحقق من الوظائف المجدولة وحذف الحساب على حساب تجريبي.
3. اختبروا استعادة كلمة المرور من البريد إلى شاشة تعيين كلمة جديدة على الهاتف، وتأكدوا من روابط التحويل في إعدادات Supabase.
4. يلزم قبول نهائي على الويب والجوال، بما فيه التسجيل، رفع السيرة والتحليل، حفظ البيانات، الوظائف السعودية، المسارات وخطة التعلم، اللغة والثيم. ملفات PDF الممسوحة لا تدعم OCR حاليًا.
5. كل الخدمات المطلوبة حاليًا مجانية؛ أخبروا صاحبة المشروع قبل أي خطوة مدفوعة.
