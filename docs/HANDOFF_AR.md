# تسليم مشروع مسارك — 12 أكتوبر 2026

هذه نسخة من كامل كود المشروع الحالي، تشمل التطبيق والخادم والاختبارات وملفات التجربة الاصطناعية. لا تشمل مفاتيح الخدمات أو node_modules أو تاريخ Git أو بيانات السيرة المخزنة على أجهزة المستخدمين.

## المنجز
- رفع وتحليل PDF النصي فقط؛ الصور وWord/DOCX غير مقبولة ولا يوجد OCR. التحليل محلي محدود بقواعد عند غياب Groq، أو عبر Groq عند تفعيله وبموافقة المستخدم.
- فصل التعليم والمشاريع والأنشطة والشهادات والخبرات والمهارات، ومراجعتها قبل الاعتماد.
- حفظ السيرة والمهارات محليًا، مع حفظ سحابي اختياري للملف والمهارات والخطة والسيرة، وتحديث ترشيحات المسارات وخطة التعلم.
- واجهات الترحيب والدخول والصفحة الرئيسية والملف.
- Supabase للتسجيل والدخول والاستعادة وحفظ الجلسة، وحفظ سحابي اختياري محمي لكل حساب. تبقى بيانات الضيف محلية ومستقلة.

## التشغيل
ثبّتوا Node.js، وافتحوا مجلد masarak في VS Code. من الطرفية:

```powershell
npm ci
npm --prefix server ci
```

انسخوا .env.example إلى .env.local بجذر التطبيق، واملؤوا رابط Supabase ومفتاح publishable. انسخوا server/.env.example إلى server/.env واملؤوا مفتاح Groq. اطلبوا بيانات الوصول من صاحبة المشروع بشكل خاص أو أنشئوا خدمات مجانية خاصة بكم. لا تضيفوا مفاتيح إلى Git ولا ترسلوها في صور أو مجموعة.

طرفية أولى:
```powershell
npm run cv-server
```

طرفية ثانية:
```powershell
npx expo start --clear
```

افتحوا Expo Go على الهاتف وامسحوا QR، والكمبيوتر والهاتف على نفس الواي فاي. تحليل السيرة يستخدم منفذ 3001؛ قد يلزم السماح لـNode على الشبكة الخاصة في جدار الحماية.

## أين نكمل
1. نجح إنشاء حساب فعلي وتسجيل الدخول والخروج على الآيفون، ونجح رفع نسخة الحساب والسيرة إلى Supabase ثم استرجاعها بالحساب نفسه على اللابتوب. إذا تعذر تحليل السيرة، تأكدوا أن خادم `3001` يعمل وأن الجوال والكمبيوتر على الشبكة نفسها.
2. بقي اختبار رابط استعادة كلمة المرور من البداية للنهاية على الهاتف. خدمة البريد الافتراضية تقبل أعضاء مشروع Supabase فقط وبحد رسالتين في الساعة. راجعوا docs/AUTH-SETUP.md، وإذا تغير عنوان LAN أو منفذ Expo حدّثوا روابط التحويل في Supabase لتطابق الجهاز الذي يشغّل التطبيق.
3. لاحقًا: دعم تبديل العربية والإنجليزية وتحسينات الواجهة وفق المرجع. المستخدم طلب تأجيل التجميل.
4. اختبروا الحفظ السحابي من صفحة الملف الشخصي واختاروا النسخة الصحيحة عند ظهور تعارض بين الجهاز والسحابة. صور PDF الممسوحة لا تدعم OCR حاليًا. نسبة التغطية تعكس المهارات المعتمدة وليست تقييمًا للاحتراف.
5. كل الخدمات المطلوبة حاليًا مجانية؛ أخبروا صاحبة المشروع قبل أي خطوة مدفوعة.

## التحقق
```powershell
node --test tests/profile-integration.test.cjs tests/auth-storage.test.cjs
npm run lint
npx tsc --noEmit
npm run test:cv-server
```

آخر فحص للحسابات والملف: 26 اختبارًا ناجحًا، lint وTypeScript ناجحان، وتصدير iOS نجح. هذه ليست إثباتًا لاختبار البريد على هاتف حقيقي. توجد تنبيهات dependencies سابقة؛ لا تستخدموا audit fix --force بلا مراجعة.

## تنظيم الملفات
src/app للشاشات، src/utils للبيانات والتحليل والحسابات، src/contexts لسياق الدخول، server للتحليل، tests لاختبارات الحسابات والملف، docs لتجهيز Supabase، وserver/README_AR.md لتفاصيل الخادم.
