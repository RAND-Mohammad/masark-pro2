# تحليل السيرة ومراجعتها

## ما يدعمه التدفق
- رفع PDF نصي فقط، حتى 10MB، مع حماية جلسة Supabase والتحقق من الملف قبل التحليل. لا OCR ولا Word.
- دون Groq: قواعد محلية لأقسام عربية وإنجليزية، لا فهم دلالي كامل. لا يحتاج الاختبار إلى مفتاح أو إرسال خارجي.
- ستة أقسام مستقلة: المهارات والمشاريع والدورات والشهادات والتعليم والخبرات. الأنشطة القديمة لا تُحذف؛ البنود غير المحسومة تبقى في منطقة مراجعة ولا تُحتسب كمؤهلات.
- لكل عنصر دليل من النص. أسماء المشاريع والكليات والتخصصات والدورات والمسميات الوظيفية لا تتحول تلقائيًا إلى مهارات. تقنيات المشروع الصريحة يمكن أن تُدرج كمهارات مستقلة.
- بيانات التعليم تفصل الجامعة والكلية والتخصص وحالة الدراسة؛ التخرج المتوقع ليس خبرة وظيفية.
- بيانات المشروع تفصل الاسم والوصف والدور والتقنيات؛ تصنيفه المبني على قواعد تقنية يظهر «مستنتجًا» بدليله، وإلا «غير محدد».
- الخبرة تشمل المسمى والجهة والمكان والتواريخ والمهام المذكورة. تُحسب مدة كل خبرة فقط بتواريخ كافية: فرق الأشهر، مع بيان التقريب للسنوات دون أشهر، وPresent حتى تاريخ التحليل المحفوظ فقط. لا يُعرض إجمالي للخبرات ولا تُجمع الفترات المتداخلة.

## المراجعة والحفظ
الأعداد للأسماء/العناصر الفريدة المختارة للاعتماد، وليست عدد كفاءات القاموس أو قياس الاحتراف. تتحدث مع الإضافة والتعديل والاستبعاد والنقل بين الأقسام. البند الخالي من الاسم لا يُحتسب، ولا تتكرر المؤهلات المتطابقة بين الدورات والشهادات.

يمكن تصحيح الحقول ونقل البند دون إسقاط حقوله الأصلية ودليله، مع تمييز الإضافة اليدوية والتصحيح. مسودة المراجعة تحفظ حتى العناصر المستبعدة؛ الاعتماد يحفظ المجموعة المختارة. السجلات القديمة مقبولة دون migration أو تغيير Supabase، ويظهر أن نتائجها قد تحتاج إعادة تحليل.

القسم الفارغ يعني «لم نستخرج معلومات» لا «المستخدم لا يملكها». الصفوف متعددة الأعمدة التي لا يمكن ربطها بثقة لا تُدمج. اتجاه العربية في PDF قد يغيّر ترتيب الملصق والقيمة؛ يُقبل ملصق معروف في الخلية نفسها، لكن لا تُعكس التواريخ لتصبح مدة موجبة.

## الاختبارات والحدود
مولّد الاختبار يبني PDF حقيقيًا بخط DejaVuSans المثبت أصلًا في البيئة، دون تنزيل أو مكتبة جديدة. البيانات وهمية بالكامل: لكل لغة 9 مهارات و3 مشاريع و5 دورات وشهادتان مستقلتان ومؤهل بكلية وتخصص وخبرتان. تُرسل الملفات إلى مسار multipart محلي فعلي، مع محاكاة التحقق من جلسة الاختبار فقط؛ يقرأ الخادم PDF الحقيقي، ويتحقق العميل من النتيجة، وتُشغّل معالجات واجهة المراجعة والحفظ وإعادة الفتح.

اختبارات واجهة الجهاز تستخدم محاكاة React Native ونظام الملفات، مع كود الحفظ والتحقق الفعلي؛ ليست تجربة على هاتف فعلي. لا تثبت مزامنة سحابية حية أو فهم كل تصميم PDF، ولا تختبر جودة مزوّد خارجي.

```sh
npm --prefix server test
node --test tests/*.test.cjs tests/*.test.mjs
npm run lint
npx --no-install tsc --noEmit
```
